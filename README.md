# Requirements
- [Python 3.14](https://www.python.org/downloads/release/python-3140/)

# Installation
```sh
git clone https://github.com/w1ghton/artists_normalizer.git
cd artists_normalizer
python -m venv venv
```

Activating:

Windows: `venv\\Scripts\\activate`

Linux and MacOS: `source venv/bin/activate`

```sh
pip install -r requirements.txt
```

# Usage

```sh
python main.py
```

You should to enter the absolute path to the folder.
